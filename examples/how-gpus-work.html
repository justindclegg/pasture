A GPU draws every pixel at once.

Each GPU core is slower than a CPU core. There are just thousands of them, and a picture is thousands of small, identical jobs.

CPU · 8 fast cores 0.0 s

Works through the image 8 pixels at a time.

GPU · 4,096 cores 0.0 s

One core per pixel. One step.

Inside the chip

Cores come in blocks called streaming multiprocessors. This toy GPU has 64 blocks of 64 cores. Every block runs the same instruction on different pixels at the same moment.
